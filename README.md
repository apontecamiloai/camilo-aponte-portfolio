# Camilo Aponte — Technical Portfolio

Technical portfolio focused on production AI systems, agentic workflows, enterprise automation, conversational AI, and knowledge engineering.

Built with:

- Astro
- TypeScript
- Tailwind CSS
- MDX
- Astro Content Collections

## Local development

```
npm install
npm run dev
```

## Build

```
npm run build
```

## Preview

```
npm run preview
```

## Deployment

Configured for Vercel.

## Content

Projects and articles are stored in Astro Content Collections (`src/content/projects`, `src/content/writing`).

## Privacy

No customer data, credentials, internal source code, or proprietary implementation details are included.
